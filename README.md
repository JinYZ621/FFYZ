# KMD《峰峰一中：青春纪元》校园地图重制版

本项目为 KMD 卡米达工作室制作的虚构校园娱乐游戏，不是峰峰一中官方产品。

## 本次版本内容

- 按用户提供的校园手绘布局重建校园建筑相对位置。
- 新增并标注：弘毅楼 A/B、弘德楼 A/B、弘远楼、求实楼、思源餐厅、行知楼 A/B、省身楼 A/B、海粟楼 A/B、格物楼、文渊馆、校园大门、树人楼、杏坛报告厅、艺体中心。
- 建筑上同时显示名称与功能。
- 新增操场、青春广场、两排电话亭及校园道路区域。
- 按建筑类型配置室内设施：教学楼、图书馆、餐厅、宿舍、实验楼、报告厅、艺体中心、澡堂、政教处和校园大门。
- 保留角色创建、键盘移动、手机虚拟摇杆、互动、跑步、精力、NPC、任务和本地存档。
- 地图弹窗同步显示建筑分区示意。

## GitHub Pages 部署

1. 先在 GitHub 仓库下载或保留旧版本备份。
2. 将本压缩包中的 `index.html`、`style.css`、`game.js`、`README.md` 上传到仓库根目录并覆盖同名文件。
3. 提交（Commit）更改。
4. 打开 GitHub Pages 页面，等待部署完成后刷新网站。
5. 如果浏览器仍显示旧版本，按 `Ctrl + F5` 强制刷新。

## 操作方式

- 电脑：WASD / 方向键移动，Shift 跑步，E 或 Enter 互动，M 打开地图，ESC 离开室内。
- 手机：使用左下角虚拟摇杆移动，底部按钮互动/跑步。
- 进度保存在当前浏览器本地，不会自动跨设备同步。

## 当前版本边界

这是单机校园探索版本。GitHub Pages 只托管静态网页，尚未接入真实多人联机服务器；在线大厅、账号系统、实时玩家同步和在线聊天需要后续独立后端。
