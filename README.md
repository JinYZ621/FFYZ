# KMD《峰峰一中：青春纪元》校园重制版

KMD 卡米达工作室原创虚构娱乐项目，非峰峰一中官方产品。

## 本版重制内容
- 全面采用正俯视（Top-down）地图，不使用45°等距视角。
- 根据用户提供的校园建筑名称和功能，重建教学区、生活区、操场、校园大门及公共活动区域。
- 建筑包括：文渊馆、格物楼、行知楼 A/B、省身楼 A/B、海粟楼 A/B、杏坛报告厅、树人楼、求实楼、弘远楼、弘毅楼 A/B、弘德楼 A/B、思源餐厅、艺体中心。
- 建筑标注名称、功能和入口；可进入教室、图书馆、实验室、报告厅、澡堂、食堂、宿舍等室内场景。
- WASD / 方向键移动，E / Enter互动，Shift跑步；手机支持虚拟摇杆。
- NPC 对话、校园探索任务、精力系统、本地存档。

## 文件结构
- `index.html`：页面结构
- `style.css`：视觉与响应式样式
- `game.js`：地图、建筑、角色、交互、任务和存档

## GitHub Pages 部署
1. 解压本压缩包。
2. 将 `index.html`、`style.css`、`game.js` 和 `README.md` 上传到仓库根目录。
3. GitHub 仓库进入 Settings → Pages。
4. 选择 Deploy from a branch，Branch 选 `main`，目录选 `/ (root)`，保存。
5. 等待 Pages 部署完成后访问网站。

无需 npm、打包工具或后端服务。

## 操作
- 电脑：WASD / 方向键移动；E 或 Enter互动；Shift跑步；Esc离开室内；M打开地图。
- 手机：左下角虚拟摇杆，屏幕按钮互动/跑步。
- 地图与设置：右上角按钮。

## 当前边界
这是可在 GitHub Pages 运行的单机静态网页游戏。真实多人在线同步、账号、实时聊天和云存档需要额外后端服务，本版没有虚构这些能力。
