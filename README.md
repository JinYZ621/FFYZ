# KMD《峰峰一中：青春纪元》正俯视像素版

**KMD卡米达原创虚构娱乐项目，非学校官方产品。**

## 地图依据
- 手绘布局图上方为北、下方为南；左侧为西、右侧为东。
- 校园地图使用统一的 100×56 世界坐标；建筑坐标按手绘图中的相对位置映射。
- 游戏主地图和小地图使用同一份建筑/设施坐标数据，不再用独立网格拼贴小地图。
- 建筑在主地图上标注名称与功能；小地图标出建筑名称，并以黄色圆点显示玩家位置。

## 已纳入建筑与功能
- 文渊馆：图书馆
- 格物楼：实验楼

- 弘德楼 A/B：女生宿舍

## 运行与部署
这是原生 HTML/CSS/JavaScript 项目，无需构建。将 `index.html`、`style.css`、`game.js` 上传到 GitHub 仓库根目录，开启 GitHub Pages 即可。

## 操作
- 电脑：WASD / 方向键移动，E 互动，Shift 跑步，M 打开地图，Esc 离开室内。
- 手机：使用屏幕左下角虚拟摇杆，点击互动按钮。
- 进度保存在当前浏览器本地。

## 说明
- 地图方向和建筑相对位置依据用户提供的手绘图；当前为像素风游戏化重绘，非测绘级地理数据。
- 校园整体建筑风格参考用户提供的航拍图；报告厅、图书馆、操场及艺体中心参考对应照片进行像素化表现。
- 当前版本为单机静态网页游戏；真实多人联机需要另行部署后端服务。
