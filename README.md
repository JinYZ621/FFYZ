# KMD《峰峰一中：青春纪元》校园地图重制版

**KMD卡米达原创虚构娱乐项目，非峰峰一中官方产品。**

## 本版地图依据
- 以用户提供的校园手绘图为布局底图，按原图比例映射为统一世界坐标；上北、下南、左西、右东。
- 操场位于最西侧，操场看台位于操场左侧（西侧）。
- 男生宿舍弘毅楼A、B的连接廊位于两栋楼左侧（西侧），宿舍入口开在连接部位。
- 女生宿舍弘德楼A、B的连接廊位于两栋楼右侧（东侧），宿舍入口开在连接部位。
- 校园主大门仍按手绘图位于南侧中部绘制；宿舍连接处所说的“大门”作为宿舍入口处理，不与校园主大门混淆。
- 杏坛报告厅位于东南侧，朝西；室内舞台在西侧，观众席朝西面向舞台。
- 文渊馆为图书馆，格物楼为实验楼；行知楼为高一、省身楼为高二、海粟楼为高三；树人楼为政教处，求实楼为澡堂，思源餐厅为学生餐厅，艺体中心为体育与艺术活动场所。
- 主地图和小地图使用同一份建筑/区域坐标数据，标注名称与功能。

## 操作
- 电脑：WASD / 方向键移动，Shift奔跑，E互动，M打开地图，ESC退出室内。
- 手机：使用屏幕摇杆和互动按钮。
- 角色资料与存档保存在当前浏览器本地。

## GitHub Pages 部署
将 `index.html`、`style.css`、`game.js`、`README.md` 放在仓库根目录，提交并推送；在仓库 Settings → Pages 中选择部署分支和根目录。
